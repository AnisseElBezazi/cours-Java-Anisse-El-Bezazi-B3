Mini jeux faits dans le cadre d'un cours de programmation orienté objet en JAVA avec Springbok, PostgreSQL et Docker

en quoi consiste le jeu : une cible mouvante, un archer et un mage qui tirent chacun leur tour sur une cible avec 3 actions au choix. À chaque tour, ils ont des paramètres différents chacun. (Le jeu n'est pas très équilibré par manque de temps mais marche ! ) 

pour lancer le projet : 

docker compose run --rm --service-ports app

ce projet a seulement pour but d'apprendre la base de Java (classe, interface, modèle, API, Repository etc...)
